# 情緒偵探社

莒光國小資優班的「認識情緒」像素風遊戲，給三到六年級學生用平板玩，一輪約 20 分鐘。

- 線上遊玩（開啟 GitHub Pages 後）：https://daimg49-gif.github.io/emotion-detective/
- 設計綱要與文字腳本：協作中心 [game-dev-lab](https://github.com/daimg49-gif/game-dev-lab) 的 `docs/specs/`
- 目前版本：v8（五章全部可玩；找線索少點一次；闖關只出現學會的招）
- 五章：🎈 園遊會的氣球、☔ 下雨的操場、📓 掉進水桶的筆記、🌫️ 起霧的舊走廊、🔦 聚光燈下的舞台；腳本見協作中心 `docs/specs/`

## 檔案

| 路徑 | 內容 |
|---|---|
| `index.html` | 目前上線的遊戲（與最新版號檔案相同） |
| `情緒偵探社_v8.html` | 目前版本；v6、v7 保留可退回 |
| `src/parts/head.html` | 頁面外殼與樣式 |
| `src/parts/content.js` | **共用內容**：人物外觀、章節卡、所有情緒卡、評語、地圖骨架、`loadChapter(n)` 換章 |
| `src/parts/ch1.js`～`ch5.js` | **各章內容**：序章、3 個委託、闖關的技能、小怪、擋路物、關卡地形。改一章的文字只改這一個檔 |
| `src/parts/stage.js` | 闖關引擎：讀這一章的 `STAGE`、`LEVEL`，不寫死任何一章 |
| `src/parts/town.js` | 校園地圖：點地圖移動、調查、委託流程 |
| `src/parts/game.js` | 主控：對話、面板、闖關切換、結算 |
| `src/stage.html` | 舊的第三章闖關原型（只給 prototype 用） |
| `tools/build_game.py` | 組出完整遊戲：`python3 tools/build_game.py 情緒偵探社_vN.html` |
| `tools/build.py` | 組出單獨的闖關試玩版 |
| `prototype/` | 闖關原型 v1～v3 |
| `assets/raw/` | ChatGPT 生的原始圖；`assets/game/` 是裁切縮小後給遊戲用的圖 |
| `tests/` | 自動測試 |

## 回歸測試清單

整章（`tests/test_game.js`，五章各跑 A、B 版本，分散在 iPad、手機橫直、筆電）：

0. 章節卡不寫情緒名稱；結案報告標題用事件名稱

1. 序章：拿圖鑑 → 跟米亞說話 → 學會深呼吸
2. 每個委託：沒線索時不能判斷情緒；找到 3 種以上線索
3. 說錯情緒會回到調查，不會卡住；只說「生氣」這類大方向的詞不能結案
3-1. 說對情緒後要挑證據：挑錯會重挑，線索本裡一定找得到可用的證據
4. 說對情緒後能選陪伴方法，結案學會這章對應的技能；闖關的 4 個技能按鈕跟著章節換
5. 開始後先選章節；委託順序可以自選；三個委託後回到公布欄，選「去闖關」再回社辦觸發闖關
5-1. 完成 1 件後可以「結束今天的調查」，結案報告把沒做的委託標成「這次沒處理」
5-2. 闖關時沒學會的技能不出現，對應關卡直接打開（暗區亮、橋搭好、磚牆變樓梯、門打開），不會卡關；第一、二、四、五章只會深呼吸也能通過
5-3. 掉進該由擋路物搭橋的坑，提示會說該用哪一招；第二章積水坑寫下來會變紙船、第五章聚光燈站著等 3 秒會變暗
6. 闖關能通過，出現結案報告、圖鑑卡片、評語、研究出處
7. 結案後回到章節選擇；全程沒有 JS 錯誤
8. 走到人旁邊「調查」按鈕會亮並顯示名字，按下去能開始調查；遠離時變暗
9. 各章委託、序章、結局的對話沒有括號補充文字
10. 找到線索時，線索內容和「找到某某線索」在同一個對話框，第二行用較淡的顏色，點一次就關
11. 闖關只顯示委託裡學會的招；開場提示還有幾招沒找到
12. 開始畫面沒有「莒光資優班・認識情緒」，署名為「本遊戲由Peiching開發，角色與情境均為虛構」

版面（`tests/test_layout.js`，9 種螢幕輪流用五章：電腦 1920、筆電 1366、iPad 橫直、手機橫直、小手機）：

1. 按鈕都在螢幕內、至少 44 像素
2. 上方資訊列和操作按鈕不蓋住遊戲畫面
3. 對話框完整顯示；對話時主角不會被對話框擋住
4. 闖關畫面寬度至少 320 像素；結算按鈕捲得到

闖關（`tests/test_stage.js`、`tests/test_bypass.js`）：

1. 三種尺寸都能通關；按鈕至少 56 像素見方
2. 硬撞生氣怪會被彈開；沒冷靜前過不去
3. 挫折怪的牆跳不過去，只有「換個角度」能變成橋
4. 暗區沒「說出來」會掉下去
5. 用錯技能有提示；情緒條滿了回到旗子
6. 站著不動不會抖

執行：

```bash
NODE_PATH=$(npm root -g) node tests/test_game.js "$PWD/情緒偵探社_v8.html" /tmp
NODE_PATH=$(npm root -g) node tests/test_layout.js "$PWD/情緒偵探社_v8.html" /tmp
NODE_PATH=$(npm root -g) node tests/test_stage.js "$PWD/prototype/stage_v3.html" /tmp
```

所有角色、情境都是虛構的，遊戲不記錄任何學生資料。
